RLG UI

The UI Architecture (RLG) has choosen Module federation to create and load Microfrontend into Angular hosts on-demand on their own hosting URLS. It is responsible for all presentational and user-interface components.

Key UI Tech Stack

  • Framework: Angular 20+ (using standalone components, lazy-loaded feature modules, RxJS, and Signals)
  • Styling: SCSS for component styling with a consistent design system
  • Components: Reusable UI components for consistent look and feel
  • Navigation: Navigation elements for seamless user experience
