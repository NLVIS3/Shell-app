RLG UI

The UI Container is the left panel microfrontend — responsible for all presentational and user-interface components.

    Key UI Tech Stack

  • Framework: Angular 15+ (using standalone components, lazy-loaded feature modules, RxJS, and Signals)
  • Styling: SCSS for component styling with a consistent design system
  • Components: Reusable UI components for consistent look and feel
  • Navigation: Navigation elements for seamless user experience
